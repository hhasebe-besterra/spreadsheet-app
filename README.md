# ブラウザ表計算ソフト

ブラウザ上で動作する軽量な表計算ソフトウェアです。外部ライブラリに依存せず、純粋なHTML/CSS/JavaScriptで実装されています。

## デモ

GitHub Pages: https://hhasebe-besterra.github.io/spreadsheet-app/

## 機能一覧

### 基本機能
- セルの編集（ダブルクリックまたはEnterキーで編集開始）
- 数式バーからの入力
- 矢印キーによるセル移動
- Tab/Enterでの次セル移動

### 数式対応
| 数式 | 説明 | 例 |
|------|------|-----|
| `=A1+B1` | 四則演算 | `=A1*B1+C1` |
| `=SUM(範囲)` | 合計 | `=SUM(A1:A10)` |
| `=AVERAGE(範囲)` | 平均 | `=AVERAGE(B1:B5)` |
| `=MAX(範囲)` | 最大値 | `=MAX(C1:C10)` |
| `=MIN(範囲)` | 最小値 | `=MIN(D1:D10)` |
| `=COUNT(範囲)` | 数値の個数 | `=COUNT(A1:A20)` |

### 書式設定
- **フォント**: ゴシック、明朝、等幅、Arial
- **文字サイズ**: 10px〜36px
- **文字スタイル**: 太字(B)、斜体(I)、下線(U)
- **文字色**: カラーピッカーで自由選択
- **背景色**: カラーピッカーで自由選択

### 配置
- 左揃え
- 中央揃え
- 右揃え

### 罫線
- 格子罫線（全セルに罫線）
- 外枠罫線（選択範囲の外側のみ）
- 罫線なし
- 線の太さ: 細/中/太

### セル操作
- **セル結合**: 複数セルを選択して結合
- **結合解除**: 結合されたセルを解除
- **列幅調整**: 列ヘッダーの右端をドラッグ
- **行高さ調整**: 行番号の下端をドラッグ

### 選択方法
| 操作 | 結果 |
|------|------|
| クリック | 1つのセルを選択 |
| ドラッグ | 範囲選択（矩形） |
| Ctrl+クリック | 個別セルを追加選択 |
| Shift+クリック | 範囲拡張 |

### Undo/Redo（元に戻す/やり直し）
- **Ctrl+Z**: 元に戻す（最大50回）
- **Ctrl+Y**: やり直し
- ツールバーの↩️/↪️ボタンでも操作可能

### ファイル操作
- **保存**: ブラウザのローカルストレージに保存（Ctrl+S）
- **読み込み**: 保存したデータを読み込み
- **CSV出力**: CSVファイルとしてダウンロード
- **CSV読込**: CSVファイルをインポート
- **自動保存**: 60秒ごとに自動保存

## キーボードショートカット

| ショートカット | 機能 |
|---------------|------|
| `Ctrl+S` | 保存 |
| `Ctrl+Z` | 元に戻す |
| `Ctrl+Y` | やり直し |
| `Ctrl+B` | 太字 |
| `Ctrl+I` | 斜体 |
| `Ctrl+U` | 下線 |

| `Esc` | 編集キャンセル |

## 技術仕様

- **フロントエンド**: HTML5, CSS3, Vanilla JavaScript (ES6+)
- **データ保存**: localStorage
- **外部依存**: なし
- **対応ブラウザ**: Chrome, Edge, Firefox, Safari (モダンブラウザ)

### データ構造

```javascript
// セルデータ
{
  "col,row": {
    value: "セルの値または数式",
    style: {
      fontFamily: "sans-serif",
      fontSize: "12px",
      bold: true,
      italic: false,
      underline: false,
      textAlign: "left",
      color: "#000000",
      bgColor: "#ffffff",
      border: { top: true, right: true, bottom: true, left: true },
      borderWidth: "1px"
    },
    merged: { cols: 2, rows: 1 }  // 結合時のみ
  }
}

// 列幅・行高さ
colWidths = { 0: 100, 1: 150, ... }
rowHeights = { 0: 30, 1: 40, ... }
```
